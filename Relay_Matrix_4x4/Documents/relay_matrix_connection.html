Relay Matrix 4x4 -- how the connections work

Simplified view. Each relay is drawn as a switch between a row wire (SIG_IN) and a column wire (SIG_OUT).

1. One relay at a crosspoint

A row wire and a column wire cross without touching. The relay sits between them: one terminal on the row, the other on the column. Only a closed relay joins the two wires.

Open: the row carries VOUT_B, the column stays idle.
Closed: VOUT_B flows into SIG_OUT2.

2. One device (4 x 4) -- example: K7 and K10 closed

All 4 relays in a row share the same row wire, so the whole SIG_IN row carries its source at all 4 relays, whether they are open or closed. Likewise, all relays in a column share the same column wire.

VOUT_A   VOUT_B   VOUT_C   VOUT_D   idle column   red ring = closing this relay would short two sources
  • K7 closed: VOUT_B (SIG_IN2) → SIG_OUT3. The SIG_OUT3 column now carries VOUT_B.
  • K10 closed: VOUT_C (SIG_IN3) → SIG_OUT2. The SIG_OUT2 column now carries VOUT_C.
  • K6 is open. It has VOUT_B on its row terminal and VOUT_C on its column terminal. Nothing is shorted now, but closing K6 would short VOUT_B to VOUT_C.
  • The same applies to every other red-ringed relay: each has one source on its row and a different source already on its column (for example K2 would short VOUT_A to VOUT_C, K11 would short VOUT_C to VOUT_B).

3. SIG_OUT columns are shared by every device

SIG_OUT1-4 are tied together across all MCP devices on the board, so each column is one long bus. A relay closed on device 0 puts its source onto that column for every device below it as well.

Device 0 K10 puts VOUT_C on SIG_OUT2. Every open relay on SIG_OUT2 in device 1 now has VOUT_C on its column terminal, so closing any of them would short its own source to VOUT_C.

4. What the GUI interlocks prevent

LockRuleBlocks in the K7 + K10 example
Column lockOnly one closed relay per SIG_OUT column, across all devices Any relay on SIG_OUT2 or SIG_OUT3 (every red ring above, including device 1)
Row lockOnly one closed relay per SIG_IN row K5, K6, K8 (SIG_IN2 already used by K7) and K9, K11, K12 (SIG_IN3 already used by K10)

With both locks on, each source connects to at most one output, and each output to at most one source. Opening a relay is never blocked.
