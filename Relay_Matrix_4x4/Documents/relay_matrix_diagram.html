Relay Matrix -- 4 x 4 (K1..K16, Omron G6L-1F DC5, SPST-NO)

Source: Schematic_relay_matrix_2026-11-03.pdf, sheet "Relays" (rev 1.0). Click a relay to toggle it and highlight the closed path.

Topology. Each relay contact connects a row node (sig_in_*) to a column node (sig_out_*). Row nodes are daisy-chained along the row through 0Ω links; each relay output node ties to its column bus through one 0Ω link. With all 0Ω fitted it is a standard crosspoint matrix: closing K(r,c) connects sig_in_r to column bus c. Removing the 0Ω links splits the board into 16 independent relays, each accessible at its own sig_in_kN / sig_out_kN pin on H19..H22.

Coil drive. Coil high side = +5V, low side = IO_cr (c = column, r = row) sunk by ULN2803 (U5/U6), driven from MCP23017 (U4) via jumper headers H10/H11.
